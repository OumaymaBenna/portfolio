Online Multi-Product E-Commerce Project
A modern e-commerce website developed with Laravel, featuring a multi-category product catalog, secure user authentication, shopping cart, and online checkout. Designed with a responsive and intuitive interface, it allows users to browse, select, and purchase products seamlessly while providing an admin dashboard for managing products, orders, and inventory.
