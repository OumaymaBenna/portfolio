This project consists of developing an e-commerce website for selling furniture and home decoration items. The website will be built using the Laravel (PHP) framework to ensure a robust, secure, and easy-to-maintain solution.

The main objective is to allow customers to browse a wide product catalog, compare items, add their selections to the cart, and place orders online while enjoying a smooth and user-friendly experience.
